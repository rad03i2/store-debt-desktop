# Store Debt Desktop | دفتر ديون المحل

برنامج Windows مكتبي عربي لإدارة حسابات الزبائن والديون والتسديدات داخل المحل.

## الحالة الحالية — Phase 3

الإصدار الحالي: **0.3.0**

### المرحلة الأولى — الأساس

- C# / .NET 10 / WPF / XAML.
- بنية MVVM.
- قاعدة SQLite محلية.
- إضافة الزبائن والبحث عنهم.
- تسجيل الديون والتسديدات.
- لوحة إجماليات يومية.
- اختصارات لوحة المفاتيح.

### المرحلة الثانية — تجربة الاستخدام

- تحسين واجهة البرنامج.
- تعديل بيانات الزبون وحذفه بأمان.
- تعديل وحذف الحركات مع إعادة حساب الرصيد.
- سجل كامل للحركات.
- نطق مبلغ الدين بعد 500ms من نجاح التسجيل.
- اختصارات أسرع للبحث والتنقل.

### المرحلة الثالثة — كشف الحساب وواتساب

- زر **كشف حساب** داخل حساب الزبون.
- إنشاء وصل حساب مرئي داخل البرنامج.
- إنشاء نسخة PNG من كشف الحساب تلقائياً.
- إنشاء نسخة نصية مناسبة للمشاركة.
- فتح محادثة الزبون في WhatsApp بالنص الجاهز.
- نسخ صورة الكشف للحافظة لتُلصق مباشرة داخل محادثة واتساب.
- أرقام الهاتف عراقية؛ يقبل البرنامج الرقم المحلي مثل `07701234567` ويحوّله إلى `9647701234567` عند فتح WhatsApp.
- قبول الإدخال بصيغ `+964` و`00964` وتحويله إلى الصيغة المحلية الموحدة.
- جميع الأرقام الظاهرة داخل البرنامج تستخدم الأرقام الإنجليزية `0-9`، بما في ذلك المبالغ والأرصدة والتواريخ وأرقام الهاتف.
- كشف الحساب يقرأ كامل سجل الزبون من قاعدة البيانات.
- صورة الكشف تعرض أحدث الحركات مع الرصيد بعد كل حركة.

## التشغيل من المصدر

```powershell
dotnet restore StoreDebtDesktop.sln
dotnet run --project src/StoreDebt.Desktop/StoreDebt.Desktop.csproj
```

GitHub Actions ينشئ أيضاً نسخة Windows x64 ذاتية الاحتواء.

## البيانات

قاعدة بيانات العمل المحلية تحفظ في:

```text
%LocalAppData%\StoreDebtDesktop\store-debt.db
```

صور كشوف الحساب تحفظ في:

```text
%LocalAppData%\StoreDebtDesktop\Statements
```

> النسخ الاحتياطي والسحابة ما زالا مؤجلين إلى مرحلة مستقلة لاحقاً.
